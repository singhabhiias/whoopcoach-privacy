# Privacy Policy — WHOOP Personal Performance Coach

**Last updated:** October 20, 2026

## 1. About this project

WHOOP Personal Performance Coach is a personal fitness and wellness project created for individual use. It uses authorised WHOOP data and information entered by the user to help review fitness trends and generate personalised insights.

## 2. Information collected

Depending on the permissions granted and features enabled, the project may access WHOOP data such as recovery, sleep, strain, workouts, profile information and body measurements. The user may also enter personal fitness information, including weight, exercise details, nutrition estimates and subjective readiness.

## 3. How information is used

Information is used to generate personal fitness summaries, identify trends, review workouts and provide general wellness suggestions. It is not intended to diagnose, treat or prevent medical conditions.

## 4. Storage and processing

The project is designed to run on the user's own computer using n8n and a locally hosted AI model through Ollama. Information may be stored in the user's local n8n data storage and other locations explicitly configured by the user.

The user is responsible for securing the computer, backups, credentials, messaging accounts and any additional integrations they enable.

## 5. Third-party services

WHOOP provides data through its API under the permissions authorised by the user. Telegram may be used to deliver reports and receive user messages. Cloudflare Tunnel may be used temporarily to provide HTTPS access to the local n8n service.

These services are governed by their respective privacy policies and terms. Information sent through an enabled third-party service may be processed by that service.

## 6. Sharing and sale of information

This project is intended for personal use. Its operator does not intend to sell personal fitness data or share it with third parties for advertising. Information may be transmitted to services that the user deliberately connects or uses as part of the project.

## 7. Data security

The project aims to minimise external processing by using local tools where practical. No method of storage or transmission is completely secure. The user should protect OAuth credentials, restrict access to n8n and avoid exposing private reports or personal data publicly.

## 8. Data retention and deletion

Information may remain in local storage, backups or connected services until the user deletes it. The user can stop integrations, revoke WHOOP API access and delete locally stored project data. Deletion from third-party services may require separate action.

## 9. Changes to this policy

This policy may be updated when the project's features, integrations or data practices change.

## 10. Contact

For questions about this personal project or this privacy policy, contact the project operator through the GitHub account that hosts this page.
